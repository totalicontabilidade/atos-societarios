⚡ Como escrever o preenchimento rápido

    

      
Descreva o que muda em linguagem simples, uma instrução por linha ou separadas por ;. O sistema não diferencia maiúsculas nem acentos. Formatos aceitos:

      

        
Razão socialrazão social para NOVA RAZÃO SOCIAL

        
Nome fantasiafantasia para NOVO FANTASIA

        
Endereço / sedeendereço para Rua X, 100, Bairro, Cidade/UF, 49000-000

        
Trocar todo o objetoobjeto para: atividade 1; atividade 2; atividade 3 (substitui tudo — tudo depois dos ":" vira a lista)

        
Trocar todas as atividadesexcluir todas as atividades; incluir atividades: atividade 1; atividade 2; atividade 3 (limpa as atuais e insere a lista)

        
Limpar as atividadesexcluir todas as atividades

        
Incluir uma atividadeincluir atividade Lanchonete

        
Excluir uma atividadeexcluir atividade Comércio de bolos

        
Capital socialcapital para R$ 50.000

        
Porte / enquadramentoporte para ME · porte para EPP · porte para DEMAIS

        
Incluir sócioincluir sócio MARIA SOUZA LIMA, CPF 111.444.777-35

        
Excluir sócioexcluir sócio JOÃO DA COSTA

      

      
Exemplo completo:

        razão social para PADARIA NOVA; fantasia para Pão Quente; endereço para Rua das Flores, 120, Centro, Aracaju/SE, 49000-000; capital para R$ 50.000; porte para EPP; incluir sócio Maria Souza, CPF 111.444.777-35; excluir sócio João Costa; excluir todas as atividades; incluir atividades: Lanchonete; Padaria; Confeitaria

      
⚠ Importante — comandos de LISTA vêm por ÚLTIMO: em incluir atividades:, objeto para: e atividades:, tudo o que vier depois dos dois-pontos é tratado como a lista de atividades (separadas por ";"). Por isso, coloque esse comando no fim. Ex.: em atividades para: A; B; C; razão para X, o "razão para X" seria entendido como mais uma atividade — o certo é razão para X; atividades para: A; B; C.

      
Observações: cada instrução também marca automaticamente a caixa correspondente em "O que muda". Endereço e sócios são preenchidos com o que o sistema consegue e ficam destacados em amarelo para você revisar. Entrada/saída de sócio: complete a qualificação (RG, endereço, quotas) na seção "Quadro societário".

Guardando, o ato fica completo no Painel de casos — com os dados preenchidos — e você o retoma quando o cliente responder.

📁 Painel de casos

    

      

        
        
        
        
      

      
Guarda neste navegador apenas o cadastro do ato: ID, empresa, CNPJ, tipo e data — não guarda o documento, os sócios nem os endereços. Se você registrar a confirmação do cliente, ficam salvos também o nome do contato e o texto que você colar (para auditoria) — evite colar dados desnecessários. Tudo isso vai junto no backup exportado. Como fica só neste navegador, exporte um backup de tempos em tempos (limpar o navegador apaga os casos).
